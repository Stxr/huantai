# 版本日志

## v0.2.3 · 2026-10-11

- 新增 SSH 远端 Codex 来源，支持独立目录、后台同步、断线缓存和跨主机会话状态隔离。
- 新增按远端独立配置的 Botmux 开关，启用后关联飞书聊天／话题，关闭后停止读取并清理自动路由。
- 新增单会话累计 Token、上下文窗口及占用比例，压缩后等待新采样，未知用量不补零。
- 整理设置页：全部快捷键集中分组，来源与同步状态分区，说明和远端配置按需展开。
- 新增 CLI 远端同步与移除命令，以及自定义 Botmux 目录支持。
- 修复远端符号链接越界读取，拒绝符号链接索引并限制日志真实路径。

## v0.2.0 · 2026-10-06

- 新增 `⌘⇧Z` 连续撤回完成，并返回对应会话。
- 新增官方 DeepSeek Harness 会话索引、压缩记录读取和原生应用唤起。
- 新增来源开关与数据目录设置，切换后刷新并保留个人状态。
- 新增默认关闭的任务音效 Hook，支持 Codex／DeepSeek Harness 与自定义音频。
- 修复新版 Codex 额度读取，支持发现桌面客户端内置 CLI。
- 新增独立 Token Pet：12级成长、USB／BLE、会话跳转及三档亮度／麦克风门槛。
- 更新 README 原生界面截图、使用指南和发布说明。
