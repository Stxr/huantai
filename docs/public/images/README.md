# README 展示素材

会话和设置截图使用当前 `PopoverView`、`SettingsView` 的原生 AppKit / SwiftUI 内容渲染。所有会话标题、回复片段、额度、重置卡与登录启动状态均为合成示例；不读取用户数据，不启动扫描、Web、账户请求或登录项注册。

`menu-bar-modes.png` 使用当前 `MenuBarIcon` 绘制，包含每日 150%、65%、5% 和每周剩余 48% 的合成状态。图标放大展示，数字颜色沿用生产逻辑。周参考点与红色消耗弧来自同一绘制实现。

截图保留正常浮窗视口，包括设置的滚动区域；它们用于展示界面，不作为真实账户接入、开机运行或菜单栏实机截屏的证明。

`wordmark.svg` 和 `platforms.svg` 是 README 品牌展示与平台标识。截图基于 `v0.1.0` 对应界面，更新功能或样式时应重新渲染并审阅。
