Codex / DeepSeek Harness 任务音效

started.mp3：任务开始（默认 Building）
completed.wav：任务完成（默认 Construction Complete）
failed.wav：任务失败（默认 Unit Lost）

替换对应文件即可。保留 started、completed、failed 文件名，扩展名可改变。
支持 wav、mp3、aiff、aif、m4a、caf。每种状态只保留一个音频文件。无需重启换台。
删除某个状态的文件后，该状态不播放音效。已有音频不会被重置或覆盖。

默认音频来源：zenvor / RA2 EVA Commander 1.0.2
